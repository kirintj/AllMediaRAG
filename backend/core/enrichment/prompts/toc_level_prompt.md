## Task
Assign hierarchical levels (1, 2, 3, ...) to the following table of contents entries.
Level 1 is the top-level chapter, level 2 is a section, level 3 is a subsection, etc.

## Input
A JSON array of title objects.

## Output
A JSON array with the same objects, each with an added "level" field.

## Titles
{{ titles }}

Output ONLY the JSON array with level fields. No other text.
