# 现代化 UI 设计规格

## 设计选择

- **风格**: 简约专业（GitHub 风格）
- **布局**: 经典三栏（左侧历史 + 中间对话 + 右侧文档）

## 配色方案

```css
--bg-primary: #ffffff
--bg-secondary: #f6f8fa
--border: #d0d7de
--text-primary: #1f2328
--text-secondary: #656d76
--accent: #0969da
--success: #2da44e
```

## 布局结构

### 左侧栏 (260px)
- Logo + 标题
- 新建对话按钮
- 历史对话列表

### 中间区 (flex: 1)
- 顶部：对话标题 + 模式切换
- 中部：消息列表（流式显示）
- 底部：输入框 + 发送按钮

### 右侧栏 (280px)
- 文档上传区（拖拽）
- 加载本地文档按钮
- 已加载文档列表
- 统计信息
- 刷新按钮

## 组件样式

- 圆角：6-12px
- 阴影：轻微投影
- 字体：系统字体栈
- 代码块：深色背景，等宽字体
